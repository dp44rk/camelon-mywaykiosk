# 내 방식 QR — 카메라 키오스크 길잡이 (스펙 v0.1)

> 2026 AI 라이프 솔루션 챌린지 출품작. 원안: AI 라이프 아이디어 챌린지 「내 방식 QR: 범용 접근성 프로필 패스」.

## 한 줄
아무 키오스크나 폰 카메라로 찍으면, 이어폰으로 **내 방식(속도·자세함·쉬운 말)** 대로 "지금 무엇을 누르면 되는지" 한 단계씩 알려준다.
키오스크가 「내 방식 QR」을 지원하면(연동 모드) 키오스크 화면 자체도 내 방식(큰 글씨·고대비·단계 축소)으로 바뀐다.

## 왜 다른가 (경쟁 구현 대비)
| | 공개된 다른 구현들 | 이 구현 |
|---|---|---|
| 동작 조건 | 키오스크가 QR 연동을 해야 함 | **연동 없는 기존 키오스크**에서도 동작 (카메라) + 연동 시 화면 전환 |
| 안내 | 화면을 바꿔 보여줌 | **목표 기반 한 단계 음성 안내** ("오른쪽 위 노란 네모, '포장'을 누르세요") |
| 쉬운 말 | 메뉴 등록 시 1회 변환 | 매 화면 실시간 변환 + **규칙 검사기**로 길이·외래어·행동 수 강제 |
| 위치·색 | – | 모델이 아니라 **규칙 코드**로 계산 (재현 가능, 환각 없음) |

## 사용자 흐름
1. **내 방식 정하기 (처음 1번, 1분)** — 목소리 속도, 글씨 보기, 키오스크 경험, 적립 사용 여부. 결과는 폰에 저장 + **프로필 QR**(가족이 대신 만들어 보내기 가능). 개인정보(이름·연락처·장애 여부) 없음.
2. **하고 싶은 것 말하기** — "아이스 아메리카노 하나, 가져갈 거야" → AI가 되묻기로 확인.
3. **찍고 듣기** — 폰을 키오스크에 비추고 큰 버튼(또는 "다음")을 누르면 한 단계 안내. 누른 뒤 다시 찍기. 폰을 계속 들고 있을 필요 없음.
4. **안전장치** — 결제 화면에서는 금액을 읽고 반드시 "네"를 받은 뒤에만 결제 버튼을 안내. 광고·세트 권유는 "더 사라는 광고예요. '아니요'를 누르세요". 3번 막히면 **직원 도움 화면**(큰 글씨로 주문 내용 표시).
5. 언제든: "다시", "천천히", "그게 뭐야?", "모르겠어".

## "쉽게 알아듣는다"의 정의 (검사기로 강제)
근거: 국립국어원 2024 고령층(70~80대 200명) 키오스크 쉬운 언어 지침 (웰던→바싹 익히기, 명세표 인자→명세표 받기 등).

| 층위 | 규칙 | 검사 방법 |
|---|---|---|
| 말 | 외래어·전문어는 쉬운 우리말. 화면에 쓰인 글자는 그대로 읽고 뜻을 붙임 ('아이스'라고 써 있어요. 차가운 거예요) | 사전 금지어가 따옴표 밖에 나오면 실패 |
| 길이 | 한 문장 최대 N어절 (기본 8, 자주 쓰는 사람 12) | 어절 수 |
| 행동 | 한 문장에 할 일 하나, 한 번 안내에 할 일 하나 | "누르세요/고르세요…" 개수 |
| 위치 | 어디(9칸) + 생김새(색 네모) + 적힌 글자 + 할 일 순서 | 규칙 코드가 생성 |
| 양 | 한 번에 문장 최대 4개, 선택지 3개까지 읽고 "더 들을까요?" | 문장 수 |
| 소리 | 속도·자세함은 프로필대로 | TTS 속도 |

실패하면 텍스트 모델로 1회 다시 쓰고, 그래도 실패하면 **템플릿 문장**으로 대체(항상 통과).

## 구조
```
[폰 웹앱 PWA]  카메라 → 흔들림/밝기 검사 → (jsQR로 키오스크 QR 감지)
      │ 사진(1024px JPEG) + 목표 + 진행 기록 + 프로필
      ▼
[중계 서버 Node]  API 키 보관
  ├ /api/step   : 비전 모델(Qwen3.8-27B 또는 Qwen3.5-9B)로 화면 이해(JSON)
  │               → 규칙 플래너(안전장치) → 위치·색 규칙 → 쉬운 말 검사기 → 문장
  ├ /api/goal   : 텍스트 모델로 목표 이해(JSON) + 되묻기 문장
  ├ /api/explain: "그게 뭐야?"
  ├ /api/tts    : Qwen3-TTS (실패 시 폰 내장 음성)
  └ /api/kiosk/*: 연동 모드 — 키오스크가 자기 화면 구조를 올리고, 폰이 프로필을 보냄
[목업 키오스크]  /kiosk/cafe.html, /kiosk/restaurant.html (외래어·광고·세트 권유·적립·결제 포함, 목업 결제)
```

## 범위 밖
실제 결제 연동, 다국어, 손끝 추적(확장 과제).
